# CS1 C++ Practice

C++ coursework with daily examples in `lesson/` and assignments in `homework/`, covering console input, arithmetic, control flow, functions, and file-based exercises.

Compile one exercise at a time with a C++ compiler, for example `g++ -std=c++17 homework/hw1.cpp -o hw1.exe`, then run `./hw1.exe` from the repository root. Some lessons use Windows-specific console helpers or relative data files, so check the selected source before running it.
